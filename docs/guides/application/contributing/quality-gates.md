# Quality gates

The SDK's managed, package-consumer, frontend, browser, and NativeAOT jobs are
defined in the root CI workflow. For Views changes, also run the focused checks
listed in the [package README](https://github.com/Runic-Artifex/runic-sdk/blob/v0.7.0-preview.3/packages/dotnet/Runic.Application.Views/README.md)
and the relevant example README. Full release verification runs through CI.
